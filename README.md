# 🎆 New Year Goals Countdown 2027

A modern and interactive **New Year Goals Countdown** website built with HTML, CSS, and JavaScript.

The project combines a real-time countdown with personal goals, animations, music controls, and a responsive modern interface.

## 🌐 Live Demo

**[View Live Demo](https://muhammadahmad152.github.io/new-year-goals-countdown/)**

## ✨ Features

* ⏳ Real-time countdown to New Year 2027
* 🎯 Personal goals section
* 🎆 Animated fireworks effects
* 🎵 Background music controls
* 🌙 Modern dark-themed UI
* 📱 Responsive design
* ⚡ Interactive JavaScript functionality
* 🎨 CSS animations and visual effects

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout, responsiveness, and animations
* **JavaScript** — Countdown logic and interactive functionality
* **Git & GitHub** — Version control and deployment
* **GitHub Pages** — Live deployment

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/muhammadahmad152/new-year-goals-countdown.git
```

### 2. Open the project

```bash
cd new-year-goals-countdown
```

### 3. Run the project

Open `index.html` in your browser.

For the best development experience, you can use **VS Code with Live Server**.
